# Vovan OS — единая система всех проектов

Здесь собрано **всё, что работает на серверах владельца**: сервисы, сайты, боты, игры, базы данных, деплои, бэкапы, VPN. Связи с 26 репозиториями GitHub.
По этим данным Astra 6 строит сайт-панель «Vovan OS» (макет — `design/reference-dashboard.png`).

## Что где
| Папка / файл | Что внутри |
|---|---|
| **`catalog/`** | **База всех проектов (49): `projects.json` для хаба, оглавление `README.md`, карточки `projects/<id>.md`, формат `SCHEMA.md`** |
| `docs/SYSTEM-MAP.md` | Карта обоих серверов: железо, сервисы и порты, домены и маршруты, Docker, таймеры, сертификаты, бэкапы, VPN |
| `docs/PROJECTS.md` | Проекты: что из какого репозитория реально работает, где и на каких доменах |
| `docs/DATABASES.md` + `docs/databases/` | Все базы (Postgres, SQLite, Redis): таблицы, поля, связи, число строк. **Без данных** |
| `docs/FOR-ASTRA.md` | Как строить сайт: экраны → откуда брать каждую цифру |
| `docs/SECURITY.md` | Что никогда не попадает в репозиторий и как это проверяется |
| `inventory/servers/*.json` | Сырой инвентарь серверов (собран `collector/collect.py`) |
| `inventory/system-graph.json` | Граф «узлы — связи» для экрана «Карта системы» |
| `inventory/links.json` | Ручные связи «репозиторий ↔ сервисы/домены/базы» с оценкой точности |
| `inventory/github-repos.json` | Каталог 26 репозиториев GitHub |
| `collector/` | Сборщик инвентаря (только чтение) и генератор документации |
| `design/` | Макет и архитектурный пакет (Excalidraw, PDF, доски 1–12) |

## Серверы
| | Сервер 78 (основной) | Сервер 198 (Алматы) |
|---|---|---|
| Роль | Все приложения, базы, игры, боты, агенты | VPN, сайт eeklera.online, os.eeklera.online, прокси доменов на 78, копии бэкапов |
| Ресурсы | 2 CPU, 2 ГБ RAM, 58 ГБ | 1 CPU, 1 ГБ RAM, 5 + 5 ГБ |

## Обновить инвентарь
```
# на каждом сервере (только чтение)
python3 collector/collect.py > inventory/servers/server-<78|198>.json
# затем документация и граф
python3 collector/build_docs.py
python3 collector/scan_projects.py > inventory/folders/server-<78|198>.json
python3 collector/build_catalog.py
```

## Этапы
1. ✅ **Инвентарь** — карта системы, проекты, схемы всех баз, граф связей.
1.5 ✅ **База всех проектов** (`catalog/`) — 49 проектов: работающие, остановленные, только в GitHub, потерянные; ничего не осталось вне каталога.
2. ⏳ **Живой API** на сервере 78: состояние сервисов, метрики, деплои, логи, GitHub, показатели проектов. Только чтение, вход владельца через auth-gateway.
3. ⏳ **Сайт-панель** (Astra 6) по `docs/FOR-ASTRA.md`.
4. ⏳ **Действия** с подтверждением: перезапуск сервиса, откат деплоя, бэкап.

Правило: каждая цифра на панели — из реального источника. Нет источника — пишем «нет данных», не рисуем.

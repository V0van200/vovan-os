# VOVAN OS / SENTRA — архитектурная карта

Снимок проверки GitHub: 04.10.2026. Владелец: V0van200.

## Открыть

1. Скачайте Vovan-OS.excalidraw.
2. В Excalidraw выберите меню → «Открыть» и укажите файл. Также можно перетащить файл на пустой холст.
3. Для всей карты используйте «Масштабировать по содержимому» (обычно Shift+1). Приближайте нужный из 12 пронумерованных разделов.
4. Текст, блоки и стрелки редактируются; карточки содержат ссылки на GitHub. Карточки сгруппированы — разгруппируйте для правки отдельных частей, если нужно.
5. Для просмотра без редактора откройте Vovan-OS.pdf: 12 страниц с текстом и ссылками. SVG содержит всю карту, PNG — обзор.

В совместной комнате импорт может изменить общий холст. Чтобы сохранить рисунок локально, откройте файл в отдельной локальной сессии редактора без подключения к комнате. Ссылка на комнату в файл не записана. Адрес сайта комнаты из этой среды ответил HTTP 403; синхронизация в комнату не выполнялась. Импорт в конкретную версию этого стороннего редактора не проверялся.

## Что проверено

GitHub connector вернул 26 репозиториев; следующая страница пуста. 25 приватных, 1 публичный. Для 22 доступны корневые каталоги; 4 имеют size=0 и не возвращают содержимое. Прочитаны 21 README (до 110 строк); у Eeklera_new_site назначение уточнено по структуре файлов. Для server-misc подтверждены 13 каталогов. Факты из README остаются заявлениями документации, а не измерениями production.

Это не рекурсивный аудит каждого файла, всех веток и Git history. Не читались значения ключей, рабочие таблицы, пользовательские переписки и память агентов. Серверы, устройства, домены и действующие процессы не опрашивались. Архитектурные схемы и структура БД — предложение для реализации; система не развёрнута. Старые проценты совпадения файлов и оценка готовности платформы не подтверждены повторно. У Eeklera и eeklera-online действительно совпадают некоторые корневые blob/tree SHA; этого недостаточно для автоматического удаления одного из проектов.

Размер GitHub в KiB не означает объём рабочей БД, всех файлов или дискового пространства. Счётчики online, uptime, GB из присланного изображения не перенесены как реальные показатели.

Файл содержит названия приватных проектов и выдержки их документации. Он предназначен владельцу и не опубликован на сайте. GitHub и серверы не изменялись.

# Реестр доменов и доступа

Раздел «Домены и доступ» сопоставляет доменные имена из каталога проектов и активных конфигураций Nginx на `de`, `78` и `198`. Для каждого имени он показывает найденные проекты, сервер, TLS-приёмник, Nginx-маршруты и upstream, а также наличие `auth`-правила в данных Nginx. Приложение за reverse proxy может иметь собственную авторизацию; отсутствие Nginx `auth` само по себе не доказывает открытый доступ.

Публичные A-записи сверены с Google Public DNS 8.8.8.8 2026-10-13 02:07 UTC. Снимок включён в `hub/site/domain-map.json`, поэтому дата на странице указывает возраст DNS-данных. Эта страница только показывает конфигурацию: она не меняет DNS, сертификаты или службы. Для автоматического контроля записей нужно добавить серверную DNS-проверку с сохранением истории и уведомлениями.

Имена, присутствующие только в каталоге проектов, тоже выводятся как «в каталоге, но не в Nginx». Это помогает отличить план/старую привязку от найденного входного виртуального хоста. Маршруты раскрываются по нажатию, чтобы список оставался понятным.

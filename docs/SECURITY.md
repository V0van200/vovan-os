# Безопасность Vovan OS

Репозиторий описывает всю систему, поэтому его утечка не должна давать доступа ни к чему.

## Никогда не коммитим
- **Секреты:** `.env`, токены ботов Telegram, ключи OpenAI/Google/GitHub, пароли, SSH-ключи, ключи VPN (AmneziaWG, Xray), сертификаты.
- **Данные:** файлы баз (`*.sqlite`, `*.db`), дампы (`*.sql`, `*.sql.gz`), бэкапы, переписки, данные игроков и клиентов, файлы пользователей.
- **Секретные ссылки** (например, `/dl-<случайный код>/`) — маскируются как `/dl-***`.

## Что можно
- **Структура:** какие сервисы, порты, домены, папки, таймеры есть.
- **Схемы баз:** таблицы, поля, связи, число строк — без самих записей.
- **Код:** сборщика и сайта панели.

## Как это обеспечено
- `collector/collect.py` маскирует всё, похожее на секрет (`mask()`): токены, пароли в адресах, длинные ключи. Значения `.env` не читаются — только факт, что файл есть.
- `.gitignore` запрещает файлы баз, дампы, ключи, `.env`.
- `scripts/check-secrets.sh` — проверка перед каждым коммитом. Установка: `ln -s ../../scripts/check-secrets.sh .git/hooks/pre-commit`.
- Живые данные для панели отдаёт **API на сервере** (следующий этап), только после входа владельца. В репозиторий они не попадают.

## Если секрет всё-таки попал в GitHub
Удалить из истории недостаточно: **сразу сменить** этот ключ/пароль/токен там, где он выдан, затем удалить его из репозитория.

# Запуск на Android

Это полный локальный сайт, не APK. Нужен Termux (актуальная версия из F-Droid или официального GitHub termux/termux-app).

1. Скачайте Vovan-OS-Android-full.zip в папку Download телефона.
2. Откройте Termux. Выполните по очереди:

```sh
pkg update
pkg install python unzip
termux-setup-storage
```

Разрешите Termux доступ к файлам. Затем:

```sh
mkdir -p ~/vovan-os
unzip -o ~/storage/downloads/Vovan-OS-Android-full.zip -d ~/vovan-os
cd ~/vovan-os/Vovan-OS
bash START-ANDROID.sh
```

3. Откройте в браузере телефона:

http://127.0.0.1:8090

Оставьте Termux работающим. Если Android останавливает его в фоне, разрешите ему работу без ограничений батареи. Остановить сайт: Ctrl+C в Termux.

Повторный запуск:

```sh
cd ~/vovan-os/Vovan-OS
bash START-ANDROID.sh
```

Если порт занят: `python start.py --no-browser --port 8091`, затем откройте http://127.0.0.1:8091. Для сохранённых в браузере задач и настроек используйте прежний порт.

Интернет нужен для первоначальной установки Termux/Python и необязательного обновления GitHub. Сам сайт работает офлайн, сервер доступен только на телефоне. Двойной клик по index.html не заменяет запуск сервера.

В архиве: все экраны сайта, иллюстрации, снимок 49 проектов, схемы баз, паспорта, документация, скрипты обновления, запуск для Android/Windows/macOS/Linux и карта Excalidraw в design/.

Это панель над сохранёнными данными, а не копии всех приложений и их рабочих баз. Живые API, деплои, команды серверам и метрики без источника не подключены. Подробности: START-HERE.md.

Проверены браузерные экраны на ширине телефона и запуск Python-сервера. На физическом Android-устройстве этот архив не тестировался.

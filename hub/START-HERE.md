# VOVAN OS — локальный сайт

Готовая панель в стиле согласованного макета. Интернет для обычного запуска не нужен. Сайт не опубликован и не меняет серверы.

## Запустить

Нужен **Python 3.10 или новее**. Никакие библиотеки, npm или базы устанавливать не нужно.

**Windows:** распакуйте весь ZIP в папку и дважды нажмите **START.bat**. Откроется браузер.

**macOS / Linux:** откройте терминал в распакованной папке и выполните:

```sh
python3 start.py
```

Адрес после запуска: **http://127.0.0.1:8080**. Окно запуска оставьте открытым. Для остановки — Ctrl+C или закройте его.

Если порт занят: `python3 start.py --port 8081` (Windows: `py -3 start.py --port 8081`). Используйте постоянный порт: локальные задачи и проекты привязаны к адресу браузера.

`index.html` не нужно открывать двойным нажатием: сайт загружает локальный JSON через небольшой сервер. Другие компьютеры и интернет не имеют доступа к этому серверу.

## Реальные данные и границы

Источник: `V0van200/vovan-os`, коммит **0e7ce2b**. Инвентаризация серверов от 04.10.2026, каталог проектов из того же коммита. В этой работе серверы не опрашивались: прочитаны файлы GitHub.

Статусы «работал», «сайт в снимке» и показатели памяти / дисков описывают сохранённое измерение. Это **не текущий онлайн**. Проекты имеют 22 статуса running, 4 live, 15 stopped, 2 repo-only, 2 lost, 3 idea, 1 empty. Связи каталога отображаются как предоставленные автором инвентаризации, а не как отдельная проверка доступности сайтов.

Цифры AI-агентов, текущие ошибки, поток логов, результат последнего деплоя и онлайн игроков **не выдуманы**: источники ещё не подключены. Пункт «Деплои» показывает найденные таймеры, но не считает их успешными релизами. Load — средняя нагрузка, а не процент CPU.

Все картинки — локальные художественные материалы, не фотографии рабочих серверов. Метаданные приватных проектов не публиковались. Сайт не обращается к CDN, аналитике, AI или внешним API при обычном открытии. Внешние GitHub / веб-ссылки открываются только по нажатию.

## Обновить снимок

### Без токенов

«Настройки» → «Импорт JSON»:

- выберите новый **snapshot.json** или резервную копию панели;
- либо выделите вместе `projects.json` из `catalog/`, `links.json`, `github-repos.json`, `system-graph.json` и оба `server-*.json` из `inventory/servers/`.

Все файлы должны относиться к одной версии инвентаризации. При неверной структуре импорт отменяется. Импортированная копия сохраняется в браузере и имеет приоритет над файлом на диске. Кнопка «Вернуться к снимку из папки сайта» отменяет этот приоритет, сохраняя ваши задачи и локальные проекты.

### Из GitHub

Включён скрипт `local/sync_github.py`. Он читает только `V0van200/vovan-os`, фиксирует один commit SHA для всех файлов и атомарно заменяет `site/snapshot.json`. Код сборщиков не запускается. При ошибке или отсутствии интернета старый снимок остаётся доступен.

Для приватного репозитория нужен GitHub-токен **только на чтение Contents**, переданный через переменную окружения `GITHUB_TOKEN` в терминале. Не вводите его в браузер, не добавляйте в код или Git.

```sh
python3 local/sync_github.py
```

После загрузки нажмите «Обновить снимок» внизу панели. Если ранее импортировали JSON в браузере, сначала вернитесь к снимку из папки сайта.

Для попытки обновления при запуске:

```sh
python3 start.py --sync
```

Без `--sync` сетевых запросов нет. Этот путь проверен на искусственных HTTP-ответах и отказах; реальный запрос с вашим токеном не выполнялся, потому что токен в среде не настроен.

## Где редактировать

- `site/index.html`, `site/styles.css`, `site/app.mjs` — интерфейс.
- `site/model.mjs` — проверка формата, сопоставление данных и граф.
- `site/snapshot.json` — готовый снимок, который читает сайт.
- `start.py` — локальный сервер; отдаёт только папку `site/` и слушает только loopback.
- `catalog/`, `inventory/`, `docs/` — исходные описания из GitHub.
- `local/build_snapshot.py` — пересборка снимка из приложенных исходных файлов.
- `local/sync_github.py` — необязательное обновление снимка из GitHub.

Новые локальные карточки и задачи живут в localStorage конкретного браузера, а не в GitHub. Для переноса используйте «Экспортировать всё». Очищение данных браузера удаляет их, если нет экспорта.

## Проверка

Проверены 16 экранов, 49 карточек, граф из 129 узлов, поиск, схемы БД, создание и сохранение задач/проектов, экспорт, корректный и ошибочный импорт, мобильная вёрстка и отсутствие внешних запросов. Также проверены запрет чужого Host/выхода из `site/` и сохранение старого снимка при ошибке синхронизации.

Для разработчика: `tests/browser-smoke.cjs` требует Playwright и Chromium, а `tests/test_local.py` использует только Python. Сервер для тестов должен быть запущен на 8080. Для пользования сайтом тестовые зависимости не нужны.
